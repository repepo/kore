    Derivation tools

    Kore builds its matrices block by block. A block couples a row of degree \(l'\) to a column of degree \(l = l' + \Delta l\), and it is a sum of radial operators (Chebyshev/Gegenbauer matrices, built by submatrices.py) times coefficients that depend on \(l\) and \(m\) (in operators.py and diff_rot.py). A spherically symmetric background couples each degree only to itself. Two backgrounds in kore depend on latitude, so they couple different degrees:

    • an imposed magnetic field \(\mathbf{B}_0\) (Magnetic field), part A of this page;
    • a differential rotation \(\Delta\Omega(r, \theta)\) (Differential rotation), part B.

    For each, this page explains why the coefficients are computed the way they are (motivation), the mathematics (method), which file and function does each step (implementation), how the result is checked and how far the checks reach (verification), and how to run the tools yourself (worked examples).

    background where kore gets the coefficients how they were obtained how they are checked
    magnetic field closed forms in bin/operators.py (lorentz*, induction*) derived once from the definitions with sympy (tests/magnetic/derive.py), turned into formulas in \(l\), \(m\) (tools/derive/fit_rows.py) and into code (tools/derive/gen_table.py) tests/magnetic/derive_check.py, row_check.py, budget_check.py, bin/ru_insane.py, comparison with conductive_IC
    differential rotation computed while kore runs, by an exact recurrence algebra (bin/angular.py, bin/diff_rot.py) nothing to fit: the algebra is exact for any degree of \(\Delta\Omega\) tests/diff_rot/angular_check.py, gen_check.py (closed forms of diff_rot_coefficients.py), quad_reference.py, tests/heat_dr/tw_sympy.py

    Prerequisites. Python 3 with numpy and scipy (kore's environment, e.g. source ~/z2/bin/activate), and sympy for the magnetic derivations (pip install sympy). The differential-rotation tools need no sympy, except tw_sympy.py. Commands are given from the repository root unless a run directory is named. The outputs shown were recorded on 2026-10-29.

    Notation. At a fixed azimuthal order \(m\) the angular functions are kore's Schmidt harmonics \(Y_l = \sqrt{4\pi/(2l+1)}\,Y_l^m\) (Condon–Shortley phase), with \(\int|Y_l|^2d\Omega = 4\pi/(2l+1)\); \(L = l(l+1)\), and \(L'\) is the \(L\) of the row. The flow is \(\mathbf{u} = \rho_0^{-1}\nabla\times\nabla\times(\rho_0 P Y_l\mathbf{r}) + \nabla\times(T Y_l\mathbf{r})\) and the magnetic field \(\mathbf{b} = \nabla\times\nabla\times(F Y_l\mathbf{r}) + \nabla\times(G Y_l\mathbf{r})\). The rows of the momentum equation are its projections \(\hat{\mathbf{r}}\cdot\nabla\times\nabla\times\) (section u, the 2-curl) and \(\hat{\mathbf{r}}\cdot\nabla\times\) (section v, the 1-curl); those of the induction equation are \(\hat{\mathbf{r}}\cdot\) (section f) and \(\hat{\mathbf{r}}\cdot\nabla\times\) (section g).

    A. Operators involving the background magnetic field

    A.1 Motivation

    The Lorentz force \((\nabla\times\mathbf{b})\times\mathbf{B}_0 + (\nabla\times\mathbf{B}_0)\times\mathbf{b}\) and the induction \(\nabla\times(\mathbf{u}\times\mathbf{B}_0)\) are products of a perturbation of degree \(l\) with a background of degree \(n\). Kore needs, for every pair of degrees, every radial term of these products, with its coefficient. With a variable density the factors \(\rho_0\) and \(\rho_0^{-1}\) add terms in \((\ln\rho_0)'\) and \((\ln\rho_0)''\). Done by hand, this algebra is long and easy to get wrong; conductive_IC has hand-derived forms for a dipole and a quadrupole at uniform density only.

    So the algebra is done by a program, once, from the definitions:

    • sympy derives each block exactly, for a given \((l, l', m)\) (tests/magnetic/derive.py). This needs no trust in a hand calculation or in another code.
    • The results are turned into formulas in \(l\) and \(m\) and written into bin/operators.py. Kore then evaluates formulas while it assembles. Calling sympy at run time instead would take seconds per block (there are thousands of blocks) and would make sympy a requirement of kore.

    A.2 Method

    Step 1: derive one block. For the chosen background, poloidal \(\mathbf{B}_0 = \nabla\times\nabla\times(h Y_n^0\mathbf{r})\) or toroidal \(\mathbf{B}_0 = \nabla\times(k Y_n^0\mathbf{r})\) (\(n\) = 1 or 2), and a column field of degree \(l\), derive.py builds the row expression:

    row equation expression
    u momentum, poloidal \(\rho_0\hat{\mathbf{r}}\cdot\nabla\times\nabla\times(\rho_0^{-1}\mathbf{G})\), \(\mathbf{G} = (\nabla\times\mathbf{b})\times\mathbf{B}_0 + (\nabla\times\mathbf{B}_0)\times\mathbf{b}\)
    v momentum, toroidal \(\rho_0\hat{\mathbf{r}}\cdot\nabla\times(\rho_0^{-1}\mathbf{G})\)
    f induction, poloidal \(\hat{\mathbf{r}}\cdot\nabla\times(\mathbf{u}\times\mathbf{B}_0)\)
    g induction, toroidal \(\hat{\mathbf{r}}\cdot\nabla\times\nabla\times(\mathbf{u}\times\mathbf{B}_0)\)

    The radial functions (\(P, T, F, G, h, k, \ln\rho_0\)) stay symbolic; only \(\theta\) is explicit. The expression is expanded into monomials, each a coefficient times \(r^p\) times derivatives of the unknown, of the background and of \(\ln\rho_0\), for example \(r^{-2}\,h\,F'''\). The coefficient of each monomial still depends on \(\theta\). It is projected on \(Y_{l'}\):

    \[ c = \frac{\int(\ldots)\,Y_{l'}^*\,d\Omega}{\int|Y_{l'}|^2d\Omega}. \]

    The integrand is a trigonometric polynomial of low degree, so 80-point Gauss–Legendre quadrature in \(\theta\) gives the integral exactly, up to round-off. The result for one block is a list of numbers, one per monomial.

    Step 2: which blocks exist (selection rules). A background of degree \(n\) multiplies the perturbation by functions of \(\theta\) of degree \(n\). Projected back on the harmonics, degree \(l\) then reaches only \(l' = l + \Delta l\) with \(|\Delta l| \le n\); the curl that turns a poloidal field into a toroidal one shifts the parity of \(\Delta l\) by one. For the dipole (\(n = 1\)), for example, the u row takes \(F\) from \(l \pm 1\) and \(G\) from \(l\); for \(n = 2\), \(F\) from \(l\) and \(l \pm 2\) and \(G\) from \(l \pm 1\). derive.py finds these rules itself: a block that does not exist comes out with no terms.

    Step 3: the form of the coefficients in \(l\) and \(m\). Multiplying by a function of \(\theta\) of degree \(n\) is multiplying by \(\cos\theta\) up to \(n\) times (or differentiating in \(\theta\), which the same recurrences express; see part B). Each multiplication by \(\cos\theta\) moves \(l\) by one, with the coefficients \(p_l = \sqrt{(l+1)^2-m^2}/(2l+1)\) and \(q_l = \sqrt{l^2-m^2}/(2l+1)\). All the square roots of a coefficient come from these factors, and the \(\phi\) derivatives bring \(im\). A block of a given \(\Delta l\) shares one product of them, the angular factor \(A(l, m, \Delta l)\):

    \(\Delta l = 0\) \(\Delta l = \mp1\) \(\Delta l = \mp2\)
    \(n = 1\) \(im\) \(\sqrt{l^2-m^2}/(2l-1)\), \(\sqrt{(l+1)^2-m^2}/(2l+3)\) —
    \(n = 2\) \(1/((2l-1)(2l+3))\) \(im\sqrt{l^2-m^2}/(2l-1)\), \(im\sqrt{(l+1)^2-m^2}/(2l+3)\) \(\frac{\sqrt{(l^2-m^2)((l-1)^2-m^2)}}{(2l-1)(2l-3)}\), \(\frac{\sqrt{((l+1)^2-m^2)((l+2)^2-m^2)}}{(2l+3)(2l+5)}\)

    What remains of each coefficient, \(c/A\), is a polynomial in \(l\). It depends on \(m\) only through \(m^2\): the background is axisymmetric, so changing the sign of \(m\) changes only the \(im\) factors, which \(A\) already holds. So every coefficient has the form

    \[ c(l, m) = A(l, m, \Delta l)\,\big[a(l) + b(l)\,m^2\big],\qquad a, b\ \text{polynomials with rational coefficients}. \]

    Step 4: find \(a\) and \(b\) by exact interpolation. derive.py gives \(c\) for a range of \((l, m)\), for example \(l\) = 3–9 and \(m\) = 0–3, some 20 to 28 points. For each monomial, polynomials \(a\), \(b\) of increasing degree are tried:

    1. their coefficients are solved by least squares from all the points (each polynomial must have fewer coefficients than there are values of \(l\), so there are more points than unknowns);
    2. each coefficient is rounded to the nearest rational with denominator \(\le 60\);
    3. the rounded polynomial is kept only if it reproduces every point to \(10^{-9}\) of the largest value (in practice \(10^{-13}\)); otherwise the next degree is tried.

    This is exact interpolation, not an approximation. The data are exact up to round-off, and the result has rational coefficients and passes through more points than it has unknowns. If the form of step 3 did not hold for some block (a wrong angular factor, a coefficient that is not a polynomial), no polynomial would pass through all the points, and the tool would print None rather than a formula that is slightly off. This is why the tool is called a fit: it finds the closed form from exact samples.

    Step 5: kore's scaling and labels. Kore's rows are derive.py's rows times \(-r^5/L'^3\) (u) or \(-r^3/L'^3\) (v, f, g), and times Hendrik for the Lorentz force (the minus sign: kore's matrix A holds minus the right-hand side). Each monomial becomes a label, the name of the radial matrix submatrices.py builds: \(X^{(d)} B^{(j)} \lambda_k\, r^p\) is {row}{-p}{code}{j}[lho{k}]ohr1_D{d} in rows u, v and {row}{-(p+1)}{code}{j}[lho{k}]_D{d} in rows f, g, with code = bpo (\(c_\mathrm{norm} h\)) or bto (\(c_\mathrm{tor} k\)) and \(\lambda_k\) the \(k\)-th derivative of \(\ln\rho_0\). An operator then returns \(-A\cdot\sum(\text{polynomial}\times\text{label})/L'^3\) for each block.

    Where each closed form in operators.py comes from:

    • degree-1 poloidal field ('axial', 'FDM' with B0_l = 1, 'G21 dipole', 'Luo_S1'): conductive_IC's hand-derived forms (commit 39487bbf), with the \((\ln\rho_0)'\) terms derived for this branch;
    • degree-2 poloidal field ('Luo_S2', 'FDM' with B0_l = 2): fitted (fit_rows.py pol 2) and generated (gen_table.py);
    • toroidal fields of degree 1 and 2: fitted (fit_rows.py tor 1, tor 2).

    A.4 Verification

    • tests/magnetic/derive_check.py (no run directory, about 40 minutes): derive.py against every closed form, term by term: conductive_IC's uniform-density operators, the \((\ln\rho_0)'\) terms, the toroidal forms, and the degree-2 tables (read from the source of operators.py). Degrees \(l\) 3–6, \(m\) 0–3.
    • tests/magnetic/row_check.py (in a run directory): what kore really assembles, i.e. the closed forms times this run's radial matrices, in their Gegenbauer bases, against derive.py evaluated with the run's own profiles. This catches a wrong label, a wrong power of \(r\) or a wrong basis, even when the closed form is right. Degrees up to \(m + 4\) by default.
    • Energy budgets (budget_check.py) and the identity \(\int\rho_0\mathbf{u}^*\cdot\mathbf{F}_L\,dV = -\mathrm{Hendrik}\,\overline{\int\mathbf{b}^*\cdot\nabla\times(\mathbf{u}\times\mathbf{B}_0)dV}\) (bin/ru_insane.py): spin_doctor computes the powers of the Lorentz force and of the induction from the eigenvectors with its own formulas (on an \((r, \theta)\) grid for toroidal and degree-2 fields), independently of the operators.

    Which degrees these checks reach. derive_check (\(l\) 3–6) and row_check with its default limit look at degrees inside the range the closed forms were fitted on. They show that the code equals the fit and the derivation there, not that the formulas hold at large \(l\). The evidence at large \(l\) is:

    • poloidal fields ('axial', 'FDM' of degree 1 and 2, 'G21 dipole', 'Luo_S1', 'Luo_S2'): the eigenvalues agree with conductive_IC, whose closed forms were derived independently, to \(6\cdot10^{-13}\) or better with lmax 63–66 (full sphere and inner core) and 79–128 (conducting inner core), and to \(10^{-9}\) for the inviscid torsional modes of 'Luo_S2' with lmax 95–191 (against conductive_IC with its inviscid bases corrected, Magnetic field);
    • toroidal fields (no independent code): the energy budgets, which sum the powers over all degrees of the run (lmax 47–64, residuals \(10^{-11}\) to \(10^{-13}\)), and the Malkus (1967) frequencies (Magnetic field, Checks). Both test the operators through whole eigenvectors, not coefficient by coefficient;
    • a one-off comparison (2026-10-30) of every fitted coefficient of the degree-2 fields with derive.py at \(l = 20\), \(m = 3\) and \(l = 31\), \(m = 7\), outside the fitting range: largest relative difference \(4.3\cdot10^{-10}\) (poloidal, 40 blocks) and \(2.0\cdot10^{-10}\) (toroidal, 34 blocks), no term missing (the round-off of derive.py's quadrature at these degrees). The degree-1 fields were not compared there.

    Add a new background field.

    1. Its shape. In bin/background_field.py, add the name to B0_TYPES (at the end: its index goes to params.dat), its \(h(r)\) and derivatives to h(r, k) (a polynomial goes in POLY; mind the parity \((-1)^n\) in a full sphere), its degree and equatorial symmetry (B0_l, symmB0), and its normalisation in B0_norm if cnorm is not a number.
    2. Its couplings. If its degree is 1 or 2, the existing operators apply unchanged: they depend on the degree, not on \(h\). For another degree \(n\): derive (rows(..., b0=('pol', n))), add \(n\)'s angular factors to fit_rows.A, find the closed forms, generate the code and add a lorentz_poln/induction_poln pair with the new labels in submatrices.py; assemble.py loops over \(\Delta l = -2..2\), so widen that loop for \(n > 2\).
    3. Check. Extend derive_check.py with the new tables (its section 5 reads them from operators.py), run row_check.py and the budgets on a run with the new field, compare at a few large \(l\) with derive.py, and compare with an independent code or an analytic result where you have one. Since 2026-10-30 there is a shorter way for any degree: see A.6.

    A.6 Any background field: the couplings from the recurrence algebra (2026-10-30)

    Motivation. The closed forms of A.2–A.5 exist for one degree at a time (1 and 2). A field made of many degrees — given degree by degree (B0 = 'general') or built from a differential rotation ('ferraro') — would need a new fit for each degree. bin/mag_algebra.py builds the couplings at run time instead, for any degrees, with the exact recurrence algebra of part B: nothing is fitted, and the result is exact up to round-off at any \(n\) and \(l\).

    Method. The background is a sum over degrees of poloidal and toroidal parts. With \(\partial_\theta P_n = -\sin\theta\,P_n'(x)\), each part is a few vectors of three kinds, a polynomial \(c(x)\) times \(\hat{\mathbf{r}}\), \(\sin\theta\,\hat{\boldsymbol\theta}\) or \(\sin\theta\,\hat{\boldsymbol\phi}\):

    part \(\mathbf{B}_0\) \(\mathbf{J}_0 = \nabla\times\mathbf{B}_0\)
    poloidal \(h_n\) \(\frac{L_0 h}{r}P_n\,\hat{\mathbf{r}} - (h' + \frac{h}{r})P_n'\sin\theta\,\hat{\boldsymbol\theta}\) \(-(h'' + \frac{2h'}{r} - \frac{L_0 h}{r^2})P_n'\sin\theta\,\hat{\boldsymbol\phi}\)
    toroidal \(k_n\) \(k\,P_n'\sin\theta\,\hat{\boldsymbol\phi}\) \(\frac{L_0 k}{r}P_n\,\hat{\mathbf{r}} - (k' + \frac{k}{r})P_n'\sin\theta\,\hat{\boldsymbol\theta}\)

    The cross products with a perturbation Field \((q, s, t)\) reduce to the operations of angular.py: \(\hat{\mathbf{r}}\times(q, s, t) = (0, t, -s)\); \(\sin\theta\,\hat{\boldsymbol\theta} = x\hat{\mathbf{r}} - \hat{\mathbf{z}}\) (so zcross); \(\sin\theta\,\hat{\boldsymbol\phi} = \hat{\mathbf{z}}\times\hat{\mathbf{r}}\), and \((\hat{\mathbf{z}}\times\hat{\mathbf{r}})\times\mathbf{F} = \hat{\mathbf{r}}(\hat{\mathbf{z}}\cdot\mathbf{F}) - \hat{\mathbf{z}}(\hat{\mathbf{r}}\cdot\mathbf{F})\); and the multiplication by \(c(x)\) (mult with the matrices \(c(X)\), \(c'(X)\)). The perturbation's components are radial monomials (\(u_r = LP/r\), \(b_\theta\)-part \(F' + F/r\), \((\nabla\times\mathbf{b})_t = -(F'' + 2F'/r - LF/r^2)\), …), so the force \(\mathbf{G} = \mathbf{J}_0\times\mathbf{b} - \mathbf{B}_0\times\mathbf{J}\) and the induction \(\mathbf{E} = \mathbf{u}\times\mathbf{B}_0\) are sums of (radial monomial) × (sparse matrix on the degrees). The rows follow from

    \[ \begin{aligned} \hat{\mathbf{r}}\cdot\nabla\times\nabla\times\mathbf{V} &= \frac{L'\,(q - (rs)')}{r^2},\\ \hat{\mathbf{r}}\cdot\nabla\times\mathbf{V} &= \frac{L'\,t}{r},\\ \rho_0\,\hat{\mathbf{r}}\cdot\nabla\times\nabla\times\frac{\mathbf{V}}{\rho_0} &= \frac{L'\,(q - (rs)' + \lambda_1 rs)}{r^2}, \end{aligned} \]

    which need one radial derivative of the monomials (product rule). Each final monomial becomes a label as in step 5 of A.2, with the profile codes hp + degree (\(c_\mathrm{norm}h_n\)) and kt + degree (\(c_\mathrm{tor}k_n\)).

    Implementation. mag_algebra.build (the products and the rows), coefficients (cached per \(m\), stored by diagonal), labels (for submatrices.py), dl_range (\(|\Delta l| \le n_\mathrm{max} + 1\), for assemble.py), block (for operators.lorentz, induction when ut.mag_algebra); the profiles degree by degree come from background_field.pol_profiles, tor_profiles.

    Verification. For degrees 1 and 2 the eigenvalues equal those of the closed forms to \(\le 6\cdot10^{-13}\) (14 cases, Magnetic field); tests/magnetic/algebra_check.py compares every block with derive.py for degrees 1–4; the energy budgets close to round-off for fields of several degrees.

    How to use it. par.mag_couplings = 'algebra' for any type, or a type that needs it: 

    par.B0 = 'general'; par.B0_profiles = {1: 'r/6 - r**3/10', 3: '0.3*r**3*(1 - r**2)'}
par.B0_tor = 'general'; par.B0_tor_profiles = {2: 'r**2*(1 - r**2)'}
    python3 tests/magnetic/algebra_check.py --quick checks degrees 1 and 3 against derive.py.

    B. Operators involving background differential rotation

    B.1 Motivation

    A rotation that varies with latitude couples each degree \(l\) of the perturbation to \(l \pm 1\), \(l \pm 2\), …, up to the degree of \(\Delta\Omega\). Kore needs those couplings for every \(l\) up to lmax, which can be a few thousand for the Sun, and for every even degree \(n\) of \(\Delta\Omega\); observed rotation profiles need \(n\) up to 12 or more. Three ways to get them were considered:

    • closed forms (Gaunt-type integrals worked out by hand) exist for \(n\) = 0 and 2 (diff_rot_coefficients.py). Each new \(n\) means a new derivation;
    • quadrature on a \(\theta\) grid (kore's former method, now quad_reference.py) works for any \(n\), but it costs \(O(\mathrm{lmax}^2)\) time and memory (177 s and 2.5 GB per rank at lmax 1025) and fails above \(l \approx 645\), where scipy's harmonics overflow;
    • an exact recurrence algebra (bin/angular.py), the method kore uses. Every function of \(\cos\theta\) that appears is a polynomial, and multiplication by \(\cos\theta\) on the harmonics is exactly a three-term recurrence. So every coupling is a short product of sparse banded matrices: exact up to round-off, for any \(n\), at any degree, in \(O(\mathrm{lmax})\) time and memory (0.014 s and 6.8 MB at lmax 1025). Nothing is fitted, and nothing needs deriving for a new profile.

    B.2 Method

    Step 1: the force. The rotation is \(\Omega = \Omega_\mathrm{ref}[1 + \Delta\Omega(r, \theta)]\) with

    \[ \Delta\Omega = \mathtt{diff\_rot\_ampl}\sum_n f_n(r)\,P_n(\cos\theta),\qquad n\ \text{even}. \]

    In the frame of \(\Omega_\mathrm{ref}\) it is the flow \(\mathbf{U}_0 = G\,\Delta\Omega\,r\sin\theta\,\hat{\boldsymbol\phi}\) (\(G\) = Gaspard), which acts on the perturbation through

    \[ \mathbf{W} = G\big[\Delta\Omega\,(im\,\mathbf{u} + 2\hat{\mathbf{z}}\times\mathbf{u}) + \sin\theta\,(r\,\partial_r\Delta\Omega\,u_r + \partial_\theta\Delta\Omega\,u_\theta)\,\hat{\boldsymbol\phi}\big], \]

    and on the heat equation through \(imG\Delta\Omega\,s\) and \(\mathbf{u}\cdot\nabla S_{tw}\), where \(S_{tw}\) is the thermal-wind entropy that balances the rotation.

    Step 2: two exact recurrences. With \(x = \cos\theta\),

    \[ x\,Y_l = p_l\,Y_{l+1} + q_l\,Y_{l-1},\qquad (1 - x^2)\frac{dY_l}{dx} = (l+1)\,q_l\,Y_{l-1} - l\,p_l\,Y_{l+1}, \]

    \(p_l = \sqrt{(l+1)^2-m^2}/(2l+1)\), \(q_l = \sqrt{l^2-m^2}/(2l+1)\), for kore's Schmidt harmonics. Written on the degree index (row = target \(l'\), column = source \(l\)), they are two tridiagonal matrices: \(X\) (multiplication by \(x\)) and \(D\) (multiplication by \(-\sin\theta\,\partial_\theta\)). Their adjoint under \(\int d\Omega\) is \(D^\dagger = 2X - D\).

    Step 3: functions of \(\theta\) become polynomials in \(X\). Multiplying by \(P_n(x)\) is the matrix \(P_n(X)\), built with the Legendre recurrence \((k+1)P_{k+1} = (2k+1)\,X P_k - k\,P_{k-1}\); \(P_n'(X)\) follows in the same way. \(P_n(X)\) has \(n + 1\) non-zero diagonals, every other one: \(P_n\) couples \(l\) to \(l' = l - n, l - n + 2, \ldots, l + n\). These are the selection rules: P→P and T→T couplings have \(|\Delta l| \le n\), even; P↔T couplings have \(|\Delta l| \le n + 1\), odd (the \(\hat{\mathbf{z}}\times\) and the curl add one degree). The matrices are exact; only their last few rows are wrong, because products of truncated matrices miss the degrees beyond the truncation. They are therefore built a few degrees beyond what is used (lmax + n + 6).

    Step 4: vector fields. A vector field is expanded as \(\mathbf{F} = \sum_l\,[\,q_l Y_l\hat{\mathbf{r}} + s_l\,r\nabla Y_l + t_l\,r\nabla Y_l\times\hat{\mathbf{r}}\,]\). The operations \(\mathbf{W}\) needs are exact sparse products of \(X\), \(D\) and diagonal matrices: multiplication by \(g(x)\), \(\hat{\mathbf{z}}\times\), \(\hat{\mathbf{z}}\times(c\,\hat{\mathbf{r}})\), and the scalar \(\sin\theta\,F_\theta\). The formulas are in the docstring of bin/angular.py and in Differential rotation, §3.

    Step 5: the 12 primitives. For one degree \(n\), with \(\Delta\Omega = f(r)\,P_n(x)\), \(\mathbf{W}\) is linear in four radial shapes: \(f\,LP/r\) (from \(u_r\)), \(f\,a\) with \(a = (rP)'/r + \lambda_1 P\) (the consoidal part), \(f\,T\) (the toroidal part), and \((rf')\,LP/r\) (the radial shear). Applying the operations of step 4 to each shape and taking the three components \(q\), \(s\), \(t\) of the result gives 4 × 3 = 12 sparse matrices \(C[k][\mathrm{shape}]\) (rows: target degree, columns: source degree).

    Step 6: from primitives to radial operators. The u row is the 2-curl \(\hat{\mathbf{r}}\cdot\nabla\times\nabla\times\) and the v row is the 1-curl \(\hat{\mathbf{r}}\cdot\nabla\times\). Applied to a field with components \((q, s, t)\), they combine \(q\) and \(s\) (u) or \(t\) (v) with radial derivatives. Combining the primitives in the same way gives, for each radial operator of the row (for example \(f\,P\), \(f\,P'\), \(f\,(\ln\rho_0)'P\), \((rf')P\)), its coefficient for every pair \((l', l)\), multiplied by \(L'\) of the target. For example, f_2C_D0P multiplies \(f\,P\) in the u row.

    Step 7: the heat equation and the thermal wind. The heat terms need only \(P_n(X)\), \(P_n'(X)\) and \(P_n'(X)\,D\). The thermal-wind entropy \(S_{tw} = \sum_n \sigma_n(r)P_n(\cos\theta)\) follows from thermal-wind balance: in Legendre space, \(D\sigma = (1-x^2)\,\partial_x S_{tw}\) is solved for the \(\sigma_n\) by forward substitution, exactly.

    Step 7b: the induction by the rotation (2026-10-30). With a magnetic field, \(\mathbf{U}_0\) also shears the field: \(\nabla\times(\mathbf{U}_0\times\mathbf{b}) = (\mathbf{b}\cdot\nabla)\mathbf{U}_0 - (\mathbf{U}_0\cdot\nabla)\mathbf{b} = G[-im\Delta\Omega\,\mathbf{b} + \sin\theta(r\partial_r\Delta\Omega\,b_r + \partial_\theta\Delta\Omega\,b_\theta)\hat{\boldsymbol\phi}]\) (the \(\hat{\mathbf{z}}\times\mathbf{b}\) terms of the two cancel). It has the structure of \(\mathbf{W}\) without its \(2\hat{\mathbf{z}}\times\mathbf{u}\), so it has its own primitives (_induction_primitives, the shapes \(f\,LF/r\), \(f(F' + F/r)\), \(fG\), \((rf')LF/r\)). The induction row f (\(\hat{\mathbf{r}}\cdot\)) sees only \(-im\Delta\Omega\,b_r\); the row g (\(\hat{\mathbf{r}}\cdot\nabla\times = L't/r\)) sees the t components, including the \(\Omega\)-effect from F (induction_coefficients, induction_block, induction_dl_range).

    Step 8: into kore. Each radial operator is a label with the profile codes zf, zd, zs + degree for \(f_n\), \(rf_n'\), \(r^2f_n''\) (and tw, tp for \(p_0\sigma_n\), \(p_0\sigma_n'\)). submatrices.py builds its matrix. A block is then \(G\sum_n\sum(\text{coefficient}\times\text{radial operator})/L'^3\), placed by assemble.py at the \(\Delta l\) of the selection rules.

    B.4 Verification

    • tests/diff_rot/angular_check.py (no run directory): each piece of the algebra against something computed another way: the harmonics against exact rational Legendre values (\(l \le 2000\)) and scipy (\(l \le 640\)), their norms up to \(l = 3000\) (also \(m\) = 400 and 1425), \(X\) and \(D\) on a grid and their adjoints, the vector operations against Gauss–Legendre projections at low degree and around \(l = 1200\), and the 12 primitives against the former quadrature builder (quad_reference.py) for \(n \le 16\). Because it checks the algebra itself, it covers every \(n\) and degrees far above what the closed forms reach.
    • tests/diff_rot/gen_check.py (in a run directory): every coupling of \(f_0\) and \(f_2\) against the independent closed forms of diff_rot_coefficients.py, for all \(l \le\) lmax and \(m \le\) mmax (recorded runs: lmax 20 and 1025, agreement to \(10^{-15}\) of the row scale), and, for \(n\) = 4 … nmax, that no coupling falls outside the \(\Delta l\) kore assembles (a coupling there would be dropped silently).
    • The induction by the rotation (2026-10-30): tests/magnetic/dr_induction_check.py compares every block of induction_block with derive.rows_dr (sympy, \(\mathbf{U}_0 = w(r)P_n\,r\sin\theta\,\hat{\boldsymbol\phi}\)) for \(n\) up to 6 and \(l\) up to 25; tests/magnetic/rigid_check.py uses that a uniform \(\Delta\Omega = c\) is a rigid rotation, \(\lambda = \lambda(\text{Gaspard } 1 + c) - imc\) exactly, for several background fields and a conducting inner core.
    • tests/heat_dr/tw_sympy.py: the thermal-wind \(\sigma_2\), \(\sigma_4\), \(\sigma_6\) derived symbolically from thermal-wind balance, against the closed forms that gen_check compares the run-time \(\sigma_n\) with.
    • Whole-system checks: bin/ru_insane.py (the assembled rows against a grid evaluation of the force), tests/diff_rot/regress.sh (A and B against an older checkout), tests/heat_dr/run_all.sh (rows, assembly, energy budgets), and the Mukhopadhyay et al. (2025) solar benchmark (run_bekki.py, Benchmarks).

    B.5 How to use it

    The recurrence algebra. Check it against the harmonics on a grid. angular.ylm_grid(m, lmax, x) returns \(Y_l\), \(\partial_\theta Y_l\) and \(imY_l/\sin\theta\):

    $ python3
>>> import sys; sys.path.insert(0, 'bin')
>>> import numpy as np, angular
>>> A = angular.Algebra.get(2, 30)                      # m = 2, degrees 0..30
>>> x = np.array([-0.7, 0.1, 0.55])
>>> Y, dY, Z = angular.ylm_grid(2, 30, x)
>>> x*Y[5], A.X.toarray()[:, 5] @ Y                     # x Y_5 = Σ_k X[k, 5] Y_k
(array([ 0.21275696, -0.01739509, -0.03535338]), array([ 0.21275696, -0.01739509, -0.03535338]))
>>> P4, dP4 = A.legendre(4)
>>> np.polynomial.legendre.Legendre.basis(4)(x)*Y[7], P4.toarray()[:, 7] @ Y
(array([-0.09618301,  0.06666419,  0.10236181]), array([-0.09618301,  0.06666419,  0.10236181]))
>>> np.nonzero(P4.toarray()[:, 7])[0]                   # P_4 couples l = 7 to l' = 3..11, every other degree
array([ 3,  5,  7,  9, 11])
>>> -np.sqrt(1 - x**2)*dY[5], A.D.toarray()[:, 5] @ Y   # D = -sinθ ∂θ
(array([ 1.1811106 , -1.58080089,  1.58869119]), array([ 1.1811106 , -1.58080089,  1.58869119]))

    Any even degree \(n\) works: the algebra builds \(P_n(X)\) and the couplings for it, so nothing has to be derived.
