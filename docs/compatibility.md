# Combining features

Most of kore's features work together: a magnetic field with differential rotation, a stratified fluid in a full
sphere, a resolved conducting mantle with rotating solids. Some combinations work only under a condition, and a few are
not supported. kore checks the parameters when a run starts and, on any combination it cannot solve, stops with a
message that says what to change. This page shows, for each pair of features and for each forcing, whether a run works,
works under a condition, or stops, and whether a test checks that its solution is right.

## How to read the tables

Each cell answers two questions: does kore run the combination, and does a test show that its solution is right?

| mark | meaning |
| --- | --- |
| ✓ | runs, and a test suite checks it: with the pointer on the mark, the suites and the runs that do (and on a code, the name of its feature) |
| ○ | runs, and no suite checks it |
| ✓<sup>1</sup>, ○<sup>a</sup> | runs under the condition of the note, and stops otherwise (note 7: kore warns, and stops only with `ferraro_policy = 'refuse'`) |
| ✗ | stops at startup, with a message |
| – | has no meaning: two values of one parameter, an inner core in a full sphere, a viscosity without a flow |

A combination counts as tested when a test run with both features compares the solution with theory, with an
independent computation, or with an energy budget that must close. The tests are in `tests/`
([Modifying kore](checking.md)).

Each feature also has requirements of its own, whatever it is combined with
([Requirements of each feature](#requirements-of-each-feature)): a ✓ or a ○ means that the pair runs when both features
meet theirs.

## The features

The tables name each feature by a short code.

| code | feature | switched on by | page |
| --- | --- | --- | --- |
| FS | a full sphere, without an inner core | `ricb = 0` | [Regularity at the centre](numerical-method.md#regularity-at-the-centre) |
| Inv | an inviscid fluid | `ViscosD = 0` (`Ek = 0`) | [Boundary conditions](numerical-method.md#boundary-conditions) |
| H0 | no flow: the field, the entropy or the composition alone | `hydro = 0` | [The field without the flow](magnetic.md#the-field-without-the-flow) |
| S | the entropy and its stratification | `thermal = 1` | [Stratification](background.md#stratification) |
| C | the composition | `compositional = 1` | [Composition](background.md#composition) |
| DR | a differential rotation | `diff_rot = 1` | [Rotation](background.md#rotation) |
| U | a background flow | `bgflow = 1` | [Background flow](bgflow.md) |
| Cf | the centrifugal deformation, at first order in the flattening | `centrifugal = 1` | [Centrifugal deformation](background.md#centrifugal-deformation) |
| Sph | the exact spheroid | `centrifugal = 1` with `centrifugal_shape = 'spheroid'` | [Flattening](background.md#flattening) |
| B | a magnetic field | `magnetic = 1` | [Magnetic field](magnetic.md) |
| cIC | a conducting inner core | `magnetic = 1` and `innercore = 'conducting, Chebys'` | [Inner core and walls](magnetic.md#inner-core-and-walls) |
| Bes | a conducting inner core at one frequency | `magnetic = 1` and `innercore = 'conducting, Bessel'` | [Forced runs](magnetic.md#forced-runs) |
| TWA | a thin conducting layer | `magnetic = 1`, and `mantle = 'TWA'` or `innercore = 'TWA'` | [Thin conducting layer](magnetic.md#thin-conducting-layer) |
| Man | a resolved conducting mantle | `magnetic = 1` and `mantle = 'resolved'` | [Resolved conducting mantle](magnetic.md#resolved-conducting-mantle) |
| Rot | the rotating solids | `rotdyn = 1` | [Rotating solids](rotating-solids.md) |
| Kd | a constant drag at the outer wall | `kappa_cmb > 0` | [Constant drag](drag.md#constant-drag-kappa_cmb) |
| Kt | the drag of the topography | `topo_drag = 'rekier'` | [Drag of the topography](drag.md#drag-of-the-topography-topo_drag-rekier) |

`innercore` and `mantle` are used only with a magnetic field. The forcings have a table of their own
([Forced runs](#forced-runs)).

- **1.** `'inverse square'` (`stratification`, `comp_stratification`) needs an inner core.
- **2.** With the flow, a viscous fluid and `m` other than 0, a deformed full sphere needs `rpower_v` ≥ 4 (the default

- **3.** `B0 = 'dipole'`, whose source is at the centre, and `B0_tor = 'Malkus'` of degree 2, which is not regular
  there, need an inner core. A `'user'` or `'general'` profile must be finite at the centre.
- **4.** The thin layer at the outer wall (`mantle = 'TWA'`).
- **5.** An inviscid fluid cannot take the push of a current sheet at its wall. B0 must meet the wall (a toroidal B0
  that vanishes there, a poloidal one that matches the field beyond), unless a conductor beyond holds the sheet: a thin
  layer that conducts (`c1_cmb` not 0) or the resolved mantle.
- **6.** `thermal_wind` 1 or 2 needs `Beyonce` other than 0 (set it after `set_scales()`).
- **7.** B0 is a steady background only if the rotation or the flow leaves it steady: the rotation must not wind it up
  (Ferraro's law), and the flow must not induce a field from it ([Background flow](bgflow.md#what-it-adds)). kore
  prints how far it is from that, warns, and with `ferraro_policy = 'refuse'` stops above $10^{-7}$. `bin/bgflow.py`
  does not write the flow of a forcing-12 run that has a field.
- **8.** A conducting solid (a conducting inner core, a thin layer that conducts, `c1` not 0, or the resolved mantle)
  turns rigidly: the differential rotation must be uniform in latitude at its wall, and the background flow a rigid
  rotation there.
- **9.** A current sheet at a slipping wall with an insulator beyond stops a deformed body: use a no-slip wall, or a
  field that meets the wall.
- **10.** `mu_i2o = 1`, and with the flow and a poloidal B0, a no-slip inner wall (`bci = 1`).
- **11.** A toroidal B0 must vanish at both walls.
- **12.** The thin layer at the outer wall.
- **13.** With the forcings that take the drag ([Forced runs](#forced-runs)).
- **14.** The thin layer on the inner core, the resolved mantle at the outer wall.
- **15.** The thin layer at the outer wall in its thin limit (`c_cmb = 0`, `mu = 1`).

## Forced runs

A forcing adds conditions of its own, on `m` and `symm`, on the walls, and on the solids that it moves or turns. Every
forced run needs the flow (`hydro = 1`) and a spherical body (`centrifugal = 0`), and none works with the rotating
solids (`rotdyn = 1`), so the table has no columns for them.

Two rules hold for every forcing.

- A steady run (`forcing_frequency = 0`) of a viscous fluid needs walls that stay in place, `bco` and `bci` 0 or 1.
- Without diffusion (`ThermaD = 0` with the entropy, `CompoD = 0` with the composition), the scalar is only carried by
  the flow. The forcing frequency, seen from the rotating fluid, must then not be zero anywhere in the fluid, and the
  background flow must have no meridional circulation; otherwise the problem has no well-behaved solution and kore
  stops.

- **a.** With `m = 2`, an inner core.
- **b.** A thin layer that does not conduct (`c1_cmb` and `c1_icb` 0).
- **c.** A wall that the forcing moves radially, where B0 reaches it, needs one permeability on both sides:
  `mu_i2o = 1` where a conducting inner core is behind it, `mu = 1` at any other wall, and `muw = 1` of a thin layer
  where it acts on B0
  ([A boundary that moves](magnetic.md#a-boundary-that-moves)). The forcing moves the inner wall (6), the outer wall
  (10), or each wall whose amplitude is not 0 (2, with one amplitude for both; 9, 14, and 7 with `m = 2`).
- **d.** With `m = 2`: the libration with `m = 0` slides the walls along themselves, which an inviscid fluid does not
  feel.
- **e.** With `m = 0`, the libration of the inner core (`forcing_amplitude_icb` not 0) behind a stress-free inner wall
  (`bci = 0`), along a conducting core or a thin layer that conducts, under a poloidal B0, stops.
- **f.** Not with `forced_walls = 'deforming'` where the forcing moves the inner wall: the default for 9 and 14, which
  then need `forced_walls = 'rigid'` or `forcing_amplitude_icb = 0`.
- **g.** With the outer wall in place (`forcing_amplitude_cmb = 0`).
- **h.** Not in a frequency scan (`rsf_frequencies`).
- **i.** The drag of the topography needs `topo_omega` in a steady run and in a frequency scan.
- **j.** The outer wall at rest and stress-free, the inner wall turning.
- **k.** A steady run needs a no-slip inner wall (`bci = 1`).

## Requirements of each feature

Each feature has requirements of its own, whatever it is combined with. kore stops on any that a run does not meet.

| Inv | a full sphere (`ricb = 0`) |
