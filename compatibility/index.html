    Combining features

    Most of kore's features work together: a magnetic field with differential rotation, a stratified fluid in a full sphere, a resolved conducting mantle with rotating solids. Some combinations work only under a condition, and a few are not supported. kore checks the parameters when a run starts and, on any combination it cannot solve, stops with a message that says what to change. This page shows, for each pair of features and for each forcing, whether a run works, works under a condition, or stops, and whether a test checks that its solution is right.

    How to read the tables

    Each cell answers two questions: does kore run the combination, and does a test show that its solution is right?

    mark meaning
    ✓ runs, and a test suite checks it: with the pointer on the mark, the suites and the runs that do (and on a code, the name of its feature)
    ○ runs, and no suite checks it
    ✓1, ○a runs under the condition of the note, and stops otherwise (note 7: kore warns, and stops only with ferraro_policy = 'refuse')
    ✗ stops at startup, with a message
    – has no meaning: two values of one parameter, an inner core in a full sphere, a viscosity without a flow

    A combination counts as tested when a test run with both features compares the solution with theory, with an independent computation, or with an energy budget that must close. The tests are in tests/ (Modifying kore).

    Each feature also has requirements of its own, whatever it is combined with (Requirements of each feature): a ✓ or a ○ means that the pair runs when both features meet theirs.

    The features

    The tables name each feature by a short code.

    code feature switched on by page
    FS a full sphere, without an inner core ricb = 0 Regularity at the centre
    Inv an inviscid fluid ViscosD = 0 (Ek = 0) Boundary conditions
    H0 no flow: the field, the entropy or the composition alone hydro = 0 The field without the flow
    S the entropy and its stratification thermal = 1 Stratification
    C the composition compositional = 1 Composition
    DR a differential rotation diff_rot = 1 Rotation
    U a background flow bgflow = 1 Background flow
    Cf the centrifugal deformation, at first order in the flattening centrifugal = 1 Centrifugal deformation
    Sph the exact spheroid centrifugal = 1 with centrifugal_shape = 'spheroid' Flattening
    B a magnetic field magnetic = 1 Magnetic field
    cIC a conducting inner core magnetic = 1 and innercore = 'conducting, Chebys' Inner core and walls
    Bes a conducting inner core at one frequency magnetic = 1 and innercore = 'conducting, Bessel' Forced runs
    TWA a thin conducting layer magnetic = 1, and mantle = 'TWA' or innercore = 'TWA' Thin conducting layer
    Man a resolved conducting mantle magnetic = 1 and mantle = 'resolved' Resolved conducting mantle
    Rot the rotating solids rotdyn = 1 Rotating solids
    Kd a constant drag at the outer wall kappa_cmb > 0 Constant drag
    Kt the drag of the topography topo_drag = 'rekier' Drag of the topography

    innercore and mantle are used only with a magnetic field. The forcings have a table of their own (Forced runs).

    Forced runs

    A forcing adds conditions of its own, on m and symm, on the walls, and on the solids that it moves or turns. Every forced run needs the flow (hydro = 1) and a spherical body (centrifugal = 0), and none works with the rotating solids (rotdyn = 1), so the table has no columns for them.

    Two rules hold for every forcing.

    • A steady run (forcing_frequency = 0) of a viscous fluid needs walls that stay in place, bco and bci 0 or 1.
    • Without diffusion (ThermaD = 0 with the entropy, CompoD = 0 with the composition), the scalar is only carried by the flow. The forcing frequency, seen from the rotating fluid, must then not be zero anywhere in the fluid, and the background flow must have no meridional circulation; otherwise the problem has no well-behaved solution and kore stops.

    Requirements of each feature

    Each feature has requirements of its own, whatever it is combined with. kore stops on any that a run does not meet.

    feature needs
    every run an even N; lmax − m + 1 a multiple of twice the number of MPI ranks (assemble.py checks it); structure = 'Wu 2005' needs r_out between 0 and 1. In a full sphere kore warns where a background profile is not regular at the centre
    Inv a full sphere (ricb = 0)
    H0 magnetic, thermal or compositional = 1, and an eigenvalue problem; not track_target = 2, which picks the mode by its kinetic energies (Following a mode)
    DR with the entropy, thermal_wind 1 or 2 needs Beyonce other than 0; diff_rot_type = 'ferraro' needs a poloidal B0
    Cf, Sph an eigenvalue problem; with the flow and a viscous fluid, bco and bci 0 or 1. The spheroid: structure = 'Boussinesq', diffusivity = 'uniform', centrifugal_q = 0 and a flattening below 1
    B Le > 0 and Em > 0, and the limits of What is supported
    cIC, Bes an inner core; bci 0 or 1; mu_i2o and sigma_i2o positive. 'conducting, Bessel' in a forced run only, and not in a frequency scan
    TWA with a viscous fluid, bco (or bci) 0 or 1 at its wall; mu other than 1 needs a thin layer or a conducting inner core at every wall
    Man mu = 1; with a viscous fluid, bco 0 or 1; r_surface > 1; a sigma_mantle that N_mantle resolves
    Rot the flow, m = 0, symm = 1, an inner core and an eigenvalue problem; a viscous fluid with bci = 1 and bco 0 or 1; Gaspard > 0 (What is supported)
    Kd, Kt the flow, a viscous fluid, a stress-free outer wall (bco = 0), Gaspard > 0; one of the two. Kt: a frequency of the flow other than 0 (What is supported)
    U a background that is symmetric about the equator and does not cross the walls. Without bgflow_profiles, a bgflow_file written for the run's ricb and, if it has a poloidal flow, for its density; a nonlinear file (bgflow.py 12 nonlinear) only at its own bgflow_Ro, a linear one at any
